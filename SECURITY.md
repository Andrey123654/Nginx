# Политика безопасности

Сообщайте об уязвимостях приватно владельцу репозитория через GitHub Security Advisory. Не создавайте публичный issue с эксплуатационными деталями.

## Границы безопасности

- сервис принимает только `.conf`, `.txt` и `.json` в UTF-8;
- размер каждого файла ограничен 5 МБ;
- исходные файлы не имеют постоянного хранения и удаляются после обработки запроса (multipart-парсер может использовать защищённый временный файл ОС);
- полный текст Nginx-конфигурации не возвращается клиенту и не пишется в отчёт;
- сетевое сканирование выполняется отдельными датчиками только по allowlist;
- веб-сервис должен быть закрыт корпоративным SSO/VPN/WAF.

Регулярно устанавливайте обновления Ubuntu, пересобирайте контейнер, обновляйте зависимости контролируемым pull request и проверяйте образ сканером уязвимостей.

Привязка `0.0.0.0:8080` делает сервис доступным через сетевые интерфейсы сервера. Ограничьте TCP/8080 корпоративными CIDR средствами UFW/nftables/security group. Для внешнего доступа используйте HTTPS reverse proxy, WAF/VPN и корпоративную аутентификацию.
